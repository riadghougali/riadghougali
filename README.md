# 💧 سقّاية

تطبيق لطلب ماء الشرب من الشاحنات في البلدة.

- **تطبيق الزبون** (`/`): يختار الكمية (50، 100، 200، 500 لتر أو أي كمية)، يحدد موقعو بـ GPS ولا على الخريطة، ويبعث الطلب. من بعد يتبّع الشاحنة على الخريطة مباشرة ويشوف المسافة.
- **تطبيق السائق** (`/driver`): يشوف الطلبات الجديدة على الخريطة، مرتّبين من الأقرب للأبعد، مع صوت تنبيه. يقبل الطلب، يفتح الطريق في Google Maps، يعيّط للزبون، ومن بعد يعلّم «وصلت» و«كمّلت».

## التشغيل

```bash
npm install
npm start
```

من بعد حل `http://localhost:3000` للزبون و `http://localhost:3000/driver` للسائق.

## الإعدادات (متغيرات البيئة)

| المتغير | الشرح | الافتراضي |
|---|---|---|
| `PORT` | المنفذ | `3000` |
| `DRIVER_CODE` | رمز دخول السائقين، **لازم تبدّلو** | `1234` |
| `PRICE_PER_100L` | سعر 100 لتر بالدينار (0 = ما يبانش) | `0` |

## ملاحظات

- الـ GPS في التيليفون يخدم غير على **HTTPS** (ولا localhost)، لذا لازم ترفع التطبيق على استضافة فيها HTTPS، كيما Render ولا Railway.
- الطلبات تتسجل في `data/orders.json`.
